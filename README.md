# Lami

Windows에서 활동·비활동 시간을 기록하고 일별·주간·월간 통계를 확인하는 앱입니다.

설치 파일과 업데이트 소식은 이 저장소의 Releases에서 배포합니다. 이 저장소에는 프로그램 소스나 사용자 활동 기록을 포함하지 않습니다.

- Windows 10/11 x64
- 기본 비활동 기준 3분
- 트레이에서 기록하고 Windows 로그인 시 자동 실행
- 일별·주간·월간 기록의 PNG 공유 카드
- 새 버전 안내와 설치 후 변경 내용 표시

사용자 기록은 사용자 PC에 저장됩니다. 업데이트 확인에는 앱 버전과 공개 배포 정보만 사용합니다.

[최신 설치 파일 다운로드](https://github.com/JUNHOCHOI0309/Lami-releases/releases/latest)

## 설치 방법

Windows 10/11 x64에서 사용할 수 있습니다.

1. [최신 버전 다운로드 페이지](https://github.com/JUNHOCHOI0309/Lami-releases/releases/latest)를 엽니다.
2. **Assets**에서 `Lami_<버전>_x64-setup.exe`를 다운로드합니다. `Source code` 압축 파일은 설치 파일이 아닙니다.
3. 이미 Lami를 사용 중이면 트레이의 발바닥 아이콘을 오른쪽 클릭하고 **종료**를 선택합니다.
4. 다운로드한 설치 파일을 실행하고 안내에 따라 설치를 마칩니다.
5. Lami를 실행하면 현재 시점부터 활동 기록이 시작됩니다.

처음 설치하는 PC에 WebView2가 없으면 설치 중 Microsoft 런타임을 다운로드하므로 인터넷 연결이 필요합니다. 현재 설치 파일은 코드 서명 없는 버전입니다. 설치 후 기록과 조회에는 계정이나 인터넷 연결이 필요하지 않습니다.

## 기본 사용법

### 기록 시작과 시간 기준

Lami를 실행하면 별도의 시작 버튼 없이 자동으로 기록합니다. 기본 설정에서는 마지막 입력 후 3분까지 활동으로 계산하고, 그 뒤부터 비활동으로 기록합니다.

마우스나 키보드 입력 없이 영상을 보거나 문서를 읽을 때도 기준 시간이 지나면 비활동으로 표시됩니다. 화면 잠금·절전·앱이 꺼져 있던 시간은 기록 공백으로 표시하며 총 기록 시간에서 제외합니다.

### 화면별 사용

| 메뉴 | 사용 방법 |
| --- | --- |
| **오늘** | 활동·비활동·총 기록 시간, 시간대별 그래프와 오늘의 타임라인을 확인합니다. |
| **일별 기록** | 날짜 버튼을 눌러 캘린더에서 지난 날짜를 선택합니다. 월·연도를 눌러 다른 달로 이동할 수 있습니다. |
| **통계** | **주간 / 월간**을 전환하고 화살표나 캘린더로 기간을 선택합니다. 그래프의 날짜를 누르면 해당 일의 기록으로 이동합니다. |
| **설정** | 비활동 기준, 로그인 시 자동 실행, 기록 보존 기간, 저장 위치와 백업을 관리합니다. |

### 창 닫기와 트레이

창의 **X**를 누르거나 최소화해도 기록은 계속됩니다. Windows 알림 영역의 발바닥 아이콘으로 다음 기능을 사용할 수 있습니다.

- **왼쪽 클릭:** 오늘의 기록 요약을 엽니다.
- **오른쪽 클릭 → 대시보드 열기:** 전체 창을 다시 엽니다.
- **오른쪽 클릭 → 설정:** 설정 화면을 엽니다.
- **오른쪽 클릭 → 종료:** 앱을 종료하고 기록을 멈춥니다.

Windows 로그인 시 자동 실행은 기본으로 켜져 있으며 트레이에서 기록을 시작합니다. **설정 → Windows 로그인 시 자동 실행**을 변경하고 **설정 저장**을 누르면 다음 로그인부터 적용됩니다.

### 기록 공유하기

1. **오늘**, **일별 기록** 또는 **통계**에서 공유할 날짜나 기간을 선택합니다.
2. 날짜·기간 옆의 **공유 아이콘**을 누릅니다. 버튼에는 아이콘만 표시됩니다.
3. 미리보기를 확인한 뒤 **이미지 저장**을 누릅니다.
4. 저장할 위치를 선택하면 PNG 파일로 저장됩니다. 이 파일을 메신저나 커뮤니티 등에 직접 공유할 수 있습니다.

기록이 없는 날짜나 기간에는 공유 버튼이 비활성화됩니다.

### 설정과 백업

비활동 기준과 자동 실행·보존 기간을 바꾼 뒤에는 **설정 저장**을 누릅니다. 기본 비활동 기준은 3분이고, 기록 자동 삭제는 기본으로 꺼져 있습니다.

기본 저장 위치는 `%LOCALAPPDATA%\PCActivityMonitor\`입니다. **설정 → 데이터와 백업 → 저장 위치 변경**에서 폴더를 선택하고 확인하면 기존 기록·설정·백업을 함께 옮깁니다. 선택한 폴더 아래에 `PCActivityMonitor` 폴더를 만들어 사용합니다.

같은 화면의 **백업 만들기**로 기록을 백업할 수 있습니다. 저장된 백업의 **복원**을 누르고 확인하면 그 시점의 기록으로 돌아갑니다. 복원 직전 기록도 자동으로 백업합니다.

### 업데이트하기

1. **설정 → 앱과 업데이트 → 업데이트 확인**을 누릅니다. 자동 확인을 켜두면 앱 시작 후와 6시간마다 새 버전을 확인합니다.
2. 새 버전이 있으면 **다운로드 페이지**를 열어 새 설치 파일을 받습니다.
3. 트레이 메뉴에서 Lami를 **종료**한 뒤 새 설치 파일을 실행합니다.
4. 설치 후 다시 실행하면 변경 내용을 확인할 수 있습니다. 기존 기록과 설정은 유지합니다.
